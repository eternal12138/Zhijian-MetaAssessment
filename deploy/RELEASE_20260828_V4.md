## 最短更新流程

将 ZIP 及同名 `.zip.sha256` 上传至 `/opt/metacognition`。
选择没有被试正在录音/提交的时段操作；前端容器替换可能短暂中断访问。
每行单独执行，报错立即停止，不要继续下一行。

```bash
cd /opt/metacognition
sha256sum -c metacognition-deploy-20260828-radar-ui-permissions-v4.zip.sha256 && unzip -o metacognition-deploy-20260828-radar-ui-permissions-v4.zip
python3 deploy/verify-release.py /opt/metacognition
docker compose --env-file .env.production build --progress=plain frontend && docker compose --env-file .env.production up -d --no-deps --no-build frontend
curl -fsS --max-time 20 http://127.0.0.1:8080/release.json
```

确认返回的 `release_id` 是本包名称（不含 `.zip`），再刷新浏览器验收。
无需另行执行全服务 build、up --build、backup.sh 或 prune。
构建保留缓存；不要添加 `--no-cache`。服务器剩余空间不足时应停止更新，不能忽略构建错误。
