# 雷达图居中与图文分区修复（v5）

发布包：`metacognition-deploy-20260828-radar-centered-v5.zip`

## 范围与前提

适用于已完成 v3 数据库迁移并正常运行的服务器，可从 v3 或 v4 更新。
与 v4 相比，仅修改前端图表、布局和测试；后端运行代码、数据库迁移、服务配置及依赖没有变化。
保留 v4 的字体/Logo 静态文件权限修复。本次不清理数据，不运行全量备份，不重建后端，不执行数据库迁移。

## 修复内容

- 避免旧 `.radar-wrap` 全局样式预留 180px 空列，将图表挤向左侧。
- 雷达图在自己的展示区域居中，并按三角形可见边界计算尺寸和垂直中心。
- 学生、教师和管理员共用布局：图表与三维数值并列，来源、分母及警告在下方完整展示。
- 窄屏单列排列；长名称、版本及图例换行，不改变统计口径和权限。

## 部署

将 ZIP 和配套 `.zip.sha256` 文件上传至 `/opt/metacognition`。
避开被试录音或提交时段：构建时旧前端继续运行，容器替换时可能短暂中断。
以下每行单独执行；出现错误就停止，不继续下一行。

```bash
cd /opt/metacognition
sha256sum -c metacognition-deploy-20260828-radar-centered-v5.zip.sha256 && unzip -o metacognition-deploy-20260828-radar-centered-v5.zip
python3 deploy/verify-release.py /opt/metacognition
docker compose --env-file .env.production build --progress=plain frontend && docker compose --env-file .env.production up -d --no-deps --no-build frontend
curl -fsS --max-time 20 http://127.0.0.1:8080/release.json
```

返回的 release_id 应为 `metacognition-deploy-20260828-radar-centered-v5`。
不要另行全服务 build、up --build、backup.sh 或清理缓存。保留上一版包用于回退。
如果构建失败（包括空间不足），先处理错误，不要强制替换正在工作的旧前端。
