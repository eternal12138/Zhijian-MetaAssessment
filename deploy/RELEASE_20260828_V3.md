## 构建与迁移

先构建，此时旧容器继续服务。保留缓存，不加 `--no-cache`，不清理镜像或数据卷。

```bash
docker compose --env-file .env.production --profile tunnel config --quiet
docker compose --env-file .env.production --profile tunnel build --progress=plain
```

确认当前没有测评、人工复核、训练、导出等活动后，进入维护窗口。仅停止业务服务，数据库和隧道保留。

```bash
docker compose --env-file .env.production stop frontend backend asr-worker extraction-worker model-training-worker export-worker
install -d -m 0700 /opt/metacognition-db-backups
umask 077
DB_BACKUP="/opt/metacognition-db-backups/before-radar-v3-$(date +%Y%m%d-%H%M%S).sql"
docker compose --env-file .env.production exec -T db sh -c 'MYSQL_PWD="$MYSQL_ROOT_PASSWORD" mysqldump --single-transaction --routines --triggers -u root "$MYSQL_DATABASE"' > "$DB_BACKUP"
echo $?
test -s "$DB_BACKUP"
```

备份命令退出码必须为 0 且文件非空。空文件或半份文件不是备份成功。不运行会重新打包全部录音的 backup.sh，但数据库备份不能省略。

```bash
docker compose --env-file .env.production run --rm --no-deps storage-permissions
docker compose --env-file .env.production run --rm --no-deps migrate
```

必须看到阶段 33、34 成功及全部迁移完成，且命令退出码为 0。失败时保留日志，不删除表，不禁用外键，不启动旧代码碰运气。
